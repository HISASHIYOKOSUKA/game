# エクリプス・サーガ

スマホ向けのブラウザ RPG。序章から最終章・エンディングまで遊べます（目安 2〜3 時間）。

## ストーリー

ブラック企業で倒れた会社員・相馬蓮が、ハズレスキル【共鳴】（ランク F）を持つ剣士レオンとして転生する物語。ドラクエ4のように章ごとに主人公が変わり、最終章でレオンが一人ずつ仲間を集めて、自分を転生させた神「ルシファー・エクリプス」に挑む。設定と章立ては [docs/story.md](docs/story.md)。

| 章 | 主人公 | 舞台 | ボス |
|---|---|---|---|
| 序章 | レオン | ルミナの町・西の森 | ウルフキング |
| 第一章 | セレナ（＋老騎士ハロルド） | ルミナ・南の岩山の洞くつ | ストーンゴーレム |
| 第二章 | ガロ（＋踊り子ミーナ） | 商業都市ベルガ・黒鉄の鉱山・ゴラン村 | トロール |
| 第三章 | ノア（＋オルガ先生） | 学院都市ソフィア・蒼晶の塔 | ヴァンパイアロード |
| 最終章 | レオン → 仲間が一人ずつ加入 | 全域・ルミナ城・終焉の神殿 | ケルベロス、ガロ、ヒドラ、雷の使徒ガルザ、赤い仮面の使徒イフラ、教団長ネメシス、ルシファー・エクリプス（3形態） |

各章の始まりは、キャラクターが動きながら会話するイベントシーン。エンディングも、ルミナの祭り・各地のその後をキャラクターが動いて演じたあと、エンドロールが流れる。

## 遊び方

- `index.html` をブラウザで開く（ローカルなら `python3 -m http.server` などで配信）
- 左下の D パッドで移動、「ダッシュ」で高速移動、「メニュー」でステータス・装備・アイテム・セーブ・音の設定
- 建物のとびらにぶつかると中に入れる。出口のマットを踏むと外に出る。店の人にはカウンターごしに話しかける
- 町の外・ダンジョンの魔物は目に見える（シンボルエンカウント）。近づくと追ってくる
- 宿屋で全回復＆セーブ。全滅すると章ごとの宿屋の前に戻り、所持金が半分になる
- ダンジョンには宝箱がある。階段で上下の階へ

## バトル

- コマンド：たたかう / 共鳴 / スキル / まほう / アイテム / にげる
- わざはレベルアップで少しずつ覚える。上位のわざほど演出が派手（疾風斬り→旋風斬り→雷光斬→烈風剣→天空剣、ファイア→フレア→メテオ など）
- 共鳴技：最終章で仲間が加わるたびに、レオンと仲間の合体技が増える。最後の戦いでは 4 人の「エクリプス・ブレイク」が使える
- ボス戦からは にげられない

## 音楽

WebAudio のチップチューン（外部ファイルなし）。オープニング、各章のテーマ、町ごとのテーマ、ダンジョン、バトル、ボスバトル、ラストバトル、エンディングなど。メニューで音楽・効果音をそれぞれ ON/OFF できる。

## 構成

- `index.html` … 画面と CSS、スクリプトの読み込み順
- `js/data.js` … キャラクター（覚えるわざ）・わざ・アイテム・装備・お店・宿屋・モンスター・出現表
- `js/map.js` … フィールドマップ生成（シード固定）と町の配置
- `js/town.js` … 町の建物・小物のドット絵（MOTHER 風）
- `js/interior.js` … 建物の中の間取り・家具・住人
- `js/dungeon.js` … ダンジョン（迷路の生成、ボス部屋、宝箱）
- `js/sprites.js` … 人物のドット絵の手続き生成（ゲスト・敵幹部・町の人など）
- `js/music.js` … 曲データとシーケンサー
- `js/story.js` … 話し手・町の人・章の設定・イベントの台本（序章〜エンディング）
- `js/core.js` … 共通処理・画像読み込み・効果音・ゲーム状態・セーブ
- `js/tiles.js` / `js/field.js` … タイル描画、フィールドの移動・人・魔物・描画
- `js/ui.js` / `js/shop.js` / `js/event.js` … メニュー、お店、イベントの実行
- `js/battle.js` / `js/fx.js` … バトルとエフェクト
- `js/main.js` … 入力・メインループ・起動
- `assets/src/` … 元の設定画（モンスター図鑑・キャラクター・ラスボス・バトルシーン）
- `assets/img/` … 設定画から切り出したドット絵（キャラ、顔、モンスター、背景）

URL の末尾に `#debug` をつけると、開発用に `window.__debug` が使える。
