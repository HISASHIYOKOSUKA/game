# エクリプス・サーガ（暫定版）

スマホ向けのブラウザ RPG。いまはフィールド探索とバトルまで遊べます。

## 遊び方

- `index.html` をブラウザで開く（ローカルなら `python3 -m http.server` などで配信）
- 左下の D パッドで移動、右下の「ダッシュ」で高速移動、「メニュー」でステータス・アイテム・セーブ
- スタートは「ルミナの町」。町の中ではモンスターは出ない
- 建物の入口（とびら）にぶつかると入れる
  - 宿屋 ひだまり亭：20G で全回復＆セーブ
  - 武器屋 アイアンハート／防具屋 まもりの盾：装備品の売り買い。買うときに誰が装備するか選べる
  - なんでも屋 ポップ：ポーションなどの消耗品
  - 民家：住人と話せる
- 看板・ポスト・ベンチ・噴水・お城にぶつかると調べられる
- メニューでキャラクターをタップすると装備を変えられる
- 町の外の草原や森を歩くとモンスターが出現。町から離れるほど強い敵が出る（町の周辺 → 辺境の地 → 魔境）

## バトル

- コマンド：たたかう / スキル / まほう / アイテム / にげる
- レオン・ガロはスキル、セレナ・ノアはまほうを使う
- 敵はコマンドの対象リストか、画面上の敵を直接タップして選べる

## 構成

- `index.html` … 画面と CSS
- `js/data.js` … キャラクター・わざ・アイテム・装備・お店・モンスターのデータ
- `js/map.js` … フィールドマップ生成（シード固定）と町の配置
- `js/town.js` … 町の建物・小物のドット絵（MOTHER 風）
- `js/game.js` … フィールド、バトル、メニュー、効果音
- `assets/src/` … 元の設定画（モンスター図鑑・キャラクター・ラスボス・バトルシーン）
- `assets/img/` … 設定画から切り出したドット絵（キャラ、顔、モンスター、背景）
