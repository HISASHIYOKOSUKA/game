# エクリプス・サーガ　ストーリー案

## 基本設定

| 項目 | 内容 |
|---|---|
| 導入 | 異世界転生 |
| 雰囲気 | 王道で熱い（シリアスとギャグを半々。町の人の会話はとぼけた味） |
| 主人公の力 | 地味スキル【共鳴】が実は最強 |
| 前世 | ブラック企業の社畜 |
| ラスボス | ルシファー・エクリプス＝主人公を転生させた張本人 |
| 構成 | ドラクエ4風。序章（レオン）→ 仲間それぞれの章 → 最終章でレオンが一人ずつ仲間を集める |
| ボリューム | 序章＋三章＋最終章（3〜5時間） |
| 結末 | 少し切ないハッピーエンド |
| 演出 | 顔グラ付きの会話イベント |

## 主人公：レオン（前世：相馬 蓮）

- 前世は 32 歳の会社員、相馬 蓮（そうま れん）。終電と休日出勤の毎日で、他人の手柄のために働きづめ、ある冬の夜に駅のホームで倒れて死ぬ。最後に思ったのは「一度くらい、誰かと本気で力を合わせてみたかった」。
- 目を覚ますと、光と闇の狭間にいる「神」が待っている。神は蓮にスキル【共鳴】を与え、ルミナの町の 17 歳の少年レオンとして転生させる。
- 神の言葉：「見せてほしい。人が、守るに値するかどうかを」

### スキル【共鳴】

- 鑑定ではランク F。説明は「触れた相手と、気持ちが少し通じやすくなる」。町では「ハズレスキル」と笑われる。
- 本当の力：心を通わせた仲間の力を引き出し、増幅する。仲間の暴走する力を安定させたり、閉じた心に触れたりもできる。
- ゲームでは**共鳴技**（レオン＋仲間の合体技）として表れる。最終章で仲間が一人加わるたびに新しい共鳴技が増える。
  - レオン＋セレナ「ルミナスエッジ」：光の刃で敵 1 体に大ダメージ、味方全員を少し回復
  - レオン＋ガロ「アースブレイカー」：大地を割って敵全体に大ダメージ
  - レオン＋ノア「蒼嵐テンペスト」：風と雷の嵐で敵全体に魔法の大ダメージ
  - 4 人「エクリプス・ブレイク」：終章で解禁

## 仲間（それぞれの章の主人公）

1. **セレナ**（16）光の癒やし手／没落貴族アルディス家の令嬢
   - 家は豪商ゴルドーのにせの証文で屋敷を奪われかける。
   - 癒やしの力が強すぎて、ときどき制御できない。最終章でレオンの【共鳴】に触れて初めて力が安定する。
   - 穏やかで世間知らずだが、いざという時は誰よりも大胆。
2. **ガロ**（20）大地の守り手／賞金稼ぎの用心棒
   - 魔物に滅ぼされた故郷の村を建て直す金のため、ゴルドーの用心棒をしている。
   - 自分の章で、雇い主ゴルドーが蝕の教団に「人の欲望の結晶」を売っていると知り、寝返る。
3. **ノア**（17）蒼晶の魔術師／エクリプス（世界の終焉）を研究する少年
   - 古文書から「百年に一度、創造主が人の欲望を量り、天秤が傾けば世界を終わらせる」という伝承を読み解いた。誰にも信じてもらえず、学院で孤立している。
   - 理屈っぽいが仲間思い。物語の謎解き担当。

### その章だけの仲間（ゲスト）

ドラクエ4のホイミンやクリフトのように、仲間の章には一時的な同行者がつく。章の終わりに別れる。

| 章 | ゲスト | 内容 |
|---|---|---|
| 第一章 | ハロルド | アルディス家に 40 年仕える老騎士。章の最後で傷を負い、屋敷を守るために残る |
| 第二章 | ミーナ | ガロの故郷ゴラン村の少女。薬師見習いで回復役。村に残って再建を手伝う |
| 第三章 | オルガ先生 | 学院でただ一人ノアの研究を信じる老教授。星の魔法を使う。塔でノアをかばって負傷する |

## ラスボス：ルシファー・エクリプス

- 世界の均衡を保つために生まれた創造主。百年ごとに人の心を見守ってきたが、長い時の中で人の「欲望」と「憎しみ」に触れすぎ、心が闇に飲まれていく。
- 自分の判断が正しいのか確かめたくて、他人の欲に使い潰された魂（蓮）を呼び寄せ、「観測者」として転生させた。蓮が人間に絶望すれば、世界を終わらせる理由になる。
- 3 つの形態（設定画どおり）：第 1 形態「堕天の使徒」→ 第 2 形態「混沌の魔神」→ 第 3 形態「終焉の神」

## 章立て（ドラクエ4風）

### 序章「ハズレスキルの剣士」レオンの章

- 前世の死と、白い狭間での神との出会い。
- レオンはルミナの町で目を覚ます。占いの館で鑑定を受け、【共鳴】ランク F と笑われる。
- 西の森のウルフの群れにひとりで挑む。【共鳴】を試しても何も起きない。「ひとりじゃ意味がない、ってことか」
- その夜、空に一瞬だけ黒い太陽が浮かぶ。「同じ夜、世界のあちこちで、黒い太陽を見上げる者たちがいた」
- 物語は、レオンがまだ知らない仲間たちの章へ移る。

### 第一章「没落令嬢の誓い」セレナの章

- ゴルドー商会の男たちが、にせの証文を盾にアルディス家の屋敷を差し押さえに来る。
- セレナは老騎士ハロルドと証拠探しへ。ルミナの宿屋で「商会の連中が南の岩山の洞くつへ荷を運んでいる」と聞く。
- 洞くつの前で、商会の男と黒いフードの男（蝕の教団）の取引を押さえる。教団の男が黒い結晶の力で呼び出した岩の巨人（ボス）を倒す。
- 帳簿で証文の偽造が明らかになり、屋敷は戻る。ゴルドーは大斧の用心棒を連れて商業都市ベルガへ逃げた。
- ハロルドは傷を負って屋敷に残り、セレナはひとり東へ旅立つ。夜空の黒い太陽と神の声。「……ひとりめ」

### 第二章「斧と誇り」ガロの章

- 商業都市ベルガ。ガロは村の再建資金のため、日当の高いゴルドーの用心棒になる。最初の仕事は北の黒鉄の鉱山の魔物退治。
- 道具屋で薬師見習いをしていた故郷の少女ミーナ（ゲスト）と再会し、いっしょに鉱山へ。
- 鉱山の奥で赤い仮面の使徒が、黒い石は「欲望の結晶」で、三年前にゴラン村を焼いた魔物も結晶から生まれたと明かす。鉱山の主トロール（ボス）と戦う。
- ゴルドー邸で問いつめると、ゴルドーはけむりだまを投げてルミナ城へ逃げる。
- ゴラン村の焼けあとでミーナは村に残ると決め、ガロは仮面の使徒を追ってひとり旅立つ。「……ふたりめ」

### 第三章「蒼き書庫の少年」ノアの章

- 学院都市ソフィア。ノアは「百年ごとに創造主が人の欲を量る」という伝承を訴えるが、信じてくれるのはオルガ先生（ゲスト）だけ。
- 蒼晶の塔の封印が破られる。教団幹部ヴラド（ヴァンパイアロード、ボス）が『創世の書』を奪おうとしていた。
- ヴラドの最後の呪いからオルガ先生がノアをかばう。『創世の書』には「天秤が欲にかたむくとき、創造主は異界より魂を呼び、観測者とする」とあった。
- ノアは観測者を探す旅へ。「……さんにんめ。そして――そろそろ、きみの番だよ。観測者」

### 最終章「導かれし者たち」レオンの章

- 半年後。母さんにお守りをもらい、レオンが旅立つ。ここから仲間が一人ずつ加わる。
  1. 東の街道で、力を暴走させながらケルベロスに囲まれたセレナを助ける。手を取った瞬間、初めて【共鳴】が発動。共鳴技「ルミナスエッジ」
  2. ベルガの門で、レオンの中の「闇の気配」を疑うガロと一騎打ち。【共鳴】がガロの記憶（焼けた村）に触れ、仲間になる。共鳴技「アースブレイカー」
  3. 蒼晶の塔でヒドラと戦うノアを助ける。ノアはレオンこそ観測者で、呼んだのは創造主ルシファーだと告げる。共鳴技「蒼嵐テンペスト」
- 4 人でルミナ城へ。王は雷の使徒ガルザに乗っ取られていた。ガルザを倒すと、王から勇者のあかしを授かる。ゴルドーは城門で捕まる。
- 大いなる蝕が始まり、玉座の前の魔法陣が天空の「終焉の神殿」へ通じる。
- 神殿で炎の使徒イフラ（ゴラン村を焼いた仮面の使徒）、教団長ネメシス（人の欲に故郷を焼かれ、世界のやり直しを望んだ女性）を倒す。
- 最上階でルシファー・エクリプスと 3 形態の決戦。レオン「たしかに前の人生はひどかった。でもこの世界で、誰かのために力を使う奴らに出会えた。人は、守るに値する！」
- 第 3 形態の前に 4 人の想いが重なり、4 人の共鳴技「エクリプス・ブレイク」が使えるようになる。

### エピローグ（少し切ないハッピーエンド）

- 闇が晴れたルシファーは、「元の世界へ、死ぬ前の瞬間に戻してあげられる」と申し出る。レオンは断り、この世界に残る。代わりに前世の記憶は少しずつ薄れていく。
- ルミナの町で英雄をたたえる祭り（紙ふぶき、町の人たち、占いばば）。
- それぞれのその後：屋敷に戻ったセレナとハロルド、ゴラン村で柱を立てるガロとミーナ、学院で講義をするノアとオルガ先生。
- 最後はレオンの家のポスト。母さんからの手紙を読むレオンは、もう前世の名前を思い出せない。それでも仲間が「レオン」と呼び、4 人は新しい旅へ歩きだす。エンドロール。

## ゲームへの反映メモ

- 章ごとに操作するキャラクター、お金、持ち物が切りかわる（序章のぶんはしまっておき、最終章で受けつぐ）。
- ゲスト・敵幹部・町の人は手続き生成のドット絵（色替えではない）。雑魚モンスターは色替えで種類を増やしている。
- 最終章では仲間がイベントで一人ずつ加わり、フィールドの隊列とバトルに入る。
- 共鳴技はレオンのコマンド「共鳴」から使う。レオンと相手の両方の MP を使い、相手のそのターンの行動も使う。
- ボス戦では「にげる」とけむりだまが使えない。
- 町の住人のセリフは章が進むごとに変える（MOTHER 風のとぼけた会話）。
