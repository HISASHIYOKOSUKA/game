# エクリプス・サーガ　ストーリー案

## 基本設定

| 項目 | 内容 |
|---|---|
| 導入 | 異世界転生 |
| 雰囲気 | 王道で熱い（シリアスとギャグを半々。町の人の会話はとぼけた味） |
| 主人公の力 | 地味スキル【共鳴】が実は最強 |
| 前世 | ブラック企業の社畜 |
| ラスボス | ルシファー・エクリプス＝主人公を転生させた張本人 |
| ボリューム | 序章＋四章（全五章、3〜5時間） |
| 結末 | 少し切ないハッピーエンド |
| 演出 | 顔グラ付きの会話イベント |

## 主人公：レオン（前世：相馬 蓮）

- 前世は 32 歳の会社員、相馬 蓮（そうま れん）。終電と休日出勤の毎日で、他人の手柄のために働きづめ、ある冬の夜に駅のホームで倒れて死ぬ。最後に思ったのは「一度くらい、誰かと本気で力を合わせてみたかった」。
- 目を覚ますと、光と闇の狭間にいる「神」が待っている。神は蓮にスキル【共鳴】を与え、ルミナの町の 17 歳の少年レオンとして転生させる。
- 神の言葉：「見せてほしい。人が、守るに値するかどうかを」

### スキル【共鳴】

- 鑑定ではランク F。説明は「触れた相手と、気持ちが少し通じやすくなる」。町では「ハズレスキル」と笑われる。
- 本当の力：心を通わせた仲間の力を引き出し、増幅する。仲間の暴走する力を安定させたり、閉じた心に触れたりもできる。
- ゲームでは**共鳴技**（レオン＋仲間の合体技）として表れる。仲間が一人加わるたびに新しい共鳴技が増える。
  - レオン＋セレナ「ルミナスエッジ」：光の刃で敵 1 体に大ダメージ、味方全員を少し回復
  - レオン＋ガロ「アースブレイカー」：大地を割って敵全体に大ダメージ
  - レオン＋ノア「蒼嵐テンペスト」：風と雷の嵐で敵全体に魔法の大ダメージ
  - 4 人「エクリプス・ブレイク」：終章で解禁

## 仲間（加入順）

1. **セレナ**（16）光の癒やし手／没落貴族アルディス家の令嬢
   - 家は豪商ゴルドーの策略で財産を奪われた。家を立て直すため、身分を隠して冒険者になる。
   - 癒やしの力が強すぎて制御できず、暴走させてしまう。レオンの【共鳴】に触れて初めて力が安定する。
   - 穏やかで世間知らずだが、いざという時は誰よりも大胆。
2. **ガロ**（20）大地の守り手／賞金稼ぎの用心棒として敵対 → 仲間に
   - 魔物に滅ぼされた故郷の村を建て直す金のため、ゴルドーの用心棒をしている。
   - 最初は「お嬢さまを連れ戻せ」という依頼でレオンたちの前に立ちふさがる（中ボス戦）。
   - 戦いの中で【共鳴】がガロの本心（守れなかった者への後悔）に触れる。ゴルドーが蝕の教団に「人の欲望」を売っていると知り、寝返る。
3. **ノア**（17）蒼晶の魔術師／エクリプス（世界の終焉）を研究する少年
   - 古文書から「百年に一度、創造主が人の欲望を量り、天秤が傾けば世界を終わらせる」という伝承を読み解いた。誰にも信じてもらえず、学院で孤立している。
   - 理屈っぽいが仲間思い。物語の謎解き担当。

## ラスボス：ルシファー・エクリプス

- 世界の均衡を保つために生まれた創造主。百年ごとに人の心を見守ってきたが、長い時の中で人の「欲望」と「憎しみ」に触れすぎ、心が闇に飲まれていく。
- 自分の判断が正しいのか確かめたくて、他人の欲に使い潰された魂（蓮）を呼び寄せ、「観測者」として転生させた。蓮が人間に絶望すれば、世界を終わらせる理由になる。
- 3 つの形態（設定画どおり）：第 1 形態「堕天の使徒」→ 第 2 形態「混沌の魔神」→ 第 3 形態「終焉の神」

## 章立て

### 序章「ハズレスキルの剣士」（今回実装）

- 前世の死と、白い狭間での神との出会い。
- レオンはルミナの町で目を覚ます。母さんにすすめられて占いの館で鑑定を受け、【共鳴】ランク F と笑われる。
- 館を出ると、門番が「アルディス家のお嬢さんが一人で西の森へ行った」と知らせに来る。
- 西の森で、魔物に囲まれ力を暴走させかけているセレナを助ける。手を取った瞬間に【共鳴】が発動し、初めての共鳴技でボス（ウルフとゴブリン）を倒す。
- セレナが仲間になる。その夜、空に一瞬だけ黒い太陽が浮かび、神の声が響く。「……始まったね」

### 第一章「没落令嬢と金の亡者」

- 東の商業都市ベルガへ。町を牛耳る豪商ゴルドーが、アルディス家の屋敷を乗っ取っている。
- 用心棒ガロとの対決（負けても進むイベント戦 → 再戦で勝利）。
- ゴルドーの金庫（鉱山跡のダンジョン）で、蝕の教団との取引の証拠を見つける。ボスはゴーレム。
- ガロが仲間に。セレナは屋敷を取り戻すが、「今は旅を続けたい」と冒険を選ぶ。

### 第二章「蒼き書庫の少年」

- 魔術学院の町と、古代の図書館「蒼晶の塔」。
- 教団の幹部ヴァンパイアが『創世の書』を奪いに塔を襲う。アンデッドの塔ダンジョン。
- ノアが仲間に。伝承の真実（創造主の天秤、異界の魂＝観測者）から、レオンは自分を転生させた神こそ世界を終わらせる存在だと気づく。

### 第三章「蝕の使徒」

- ルミナ城の門が閉ざされた理由が明かされる。国王が教団に取り込まれていた。
- 火山・雪山・空の浮島で教団の三使徒を追う（バトル背景のバリエーションを使う）。最後はダークドラゴン。
- 大いなる蝕が始まり、空に黒い太陽が昇る。

### 終章「終焉の神」

- 崩壊する世界の神殿で、ルシファー・エクリプスと 3 形態の決戦。
- レオン「前の人生で、俺は誰かの欲に使い潰されて終わった。でもこの世界で、誰かのために力を使う奴らに出会えた」
- 仲間 4 人の想いを【共鳴】でルシファーに届け、闇の奥に残っていた最初の光を取り戻す。

### エピローグ（少し切ないハッピーエンド）

- 正気に戻ったルシファーは均衡の神として眠りにつく前に、「元の世界へ、死ぬ前の瞬間に戻してあげられる」と申し出る。
- レオンはこの世界に残ることを選ぶ。代わりに前世の記憶は少しずつ薄れていく。
- 最後の場面はルミナの町。母さんからの手紙をポストから受け取るレオンは、もう前世の名前を思い出せない。それでも仲間は「レオン」と呼んでくれる。

## ゲームへの反映メモ

- 主人公は最初ひとり。仲間はイベントで順に加わり、フィールドの隊列とバトルに入る。
- 共鳴技はレオンのコマンド「共鳴」から使う。レオンと相手の両方の MP を使い、相手のそのターンの行動も使う。
- ボス戦では「にげる」とけむりだまが使えない。
- 町の住人のセリフは章が進むごとに変える（MOTHER 風のとぼけた会話）。
